# hillo.co.za

The Hillo studio site, plus the Hillo Receptionist product page.

- `index.html` + `img/` — hillo.co.za
- `receptionist/` — hillo.co.za/receptionist (Hillo Receptionist landing page and its WhatsApp share image `og.png`)

Hosted on Cloudflare Pages (project `hillo-site`). Every push to `main` deploys automatically.
Build settings: framework None, no build command, output directory empty.

Workflow: Claude commits and pushes approved changes to `main`; nothing is uploaded by hand.
